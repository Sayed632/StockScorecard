# Context Intelligence Layer

Built from the research-sites menu (Pulse, PIB, Trendlyne/ET-style, sector themes).

## What it does
- Pulls **free Google News RSS** queries (not full scrape of 29 sites)
- Tags **policy** (RBI, PLI, GST, defence orders…)
- Tags **sectors** (pharma, defence, banks, IT, EV…)
- Telegram: **Context Intelligence** with tone + headlines

## Schedule
Mon–Fri ~09:30 IST and ~15:30 IST  
Actions → Context Intelligence → Run workflow

## Limits
- Headlines can lag or duplicate
- Not a substitute for price action / stops
- MF/PMS/unlisted sites from the menu are **not** wired (equity swing focus)
